# Easy SE Mark

AI 辅助开发的面向游戏策划与音效制作协作的轻量化视频标注工具。

在游戏录屏中添加文字标注，利用文字标注的起止时间表达音效所需长度，导出带标注的视频交由音效参考。

## 主要功能

- 支持 MP4 格式的 H.264、H.265 和 AV1 视频。
- 使用 I / O 快捷键设置音效标记的入点与出点。
- 在列表中直接修改音效名称、开始时间和结束时间。
- 在视频预览中拖动文字以调整标注位置。
- 自动分配标记颜色，统一调整文字大小。
- 保存与打开项目，继续编辑已有标注。

## 快速开始

1. 打开程序，导入 MP4 文件。
2. 定位到音效开始的位置，按 I 设置入点。
3. 定位到音效结束的位置，按 O 完成标记。
4. 在左侧列表修改音效名称。
5. 点击导出，选择目标目录，生成带文字标注的 MP4。

## 导出规格

- 格式：MP4
- 视频编码：H.264
- 分辨率：与原视频一致
- 帧率：30 fps
- 文件大小：不超过 100 MB
- 有源音轨时：转码为 AAC
